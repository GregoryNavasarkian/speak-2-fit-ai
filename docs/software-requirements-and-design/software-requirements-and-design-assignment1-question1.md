The following are the architecturally significant requirements with their implied quality attributes for Speak-2-Fit-AI.

|   Requirement (ASR)   |   Implied Quality Attributes (QAs)   |
|----------|----------|
|   Backend should return the transcribed texts and format in json within 10 seconds   |   Performance Efficiency (PE)   |
|   After the user confirms the outputted json text it should be stored in the Mongo DB within 5 seconds   |   Maintainability (MA) & Reliability (RE)   |
|   The system must transcribe voice input to text accurately using Gemini   |  Reliability (RE), Performance Efficiency (PE) & Interaction Capability (IC)   |
|   Software must be responsive across different devices   |   Compatibility (CO) & flexibility (FE)   |
|   System must allow users to maintain their exercise data in tabular or graphical form   |   Interaction Capability (IC) & Performance Efficiency (PE)   |
